# Architecture Visualizations

This directory is reserved for high-level architectural diagrams of the Operating System project.

![Architecture](architecture.png)

## Contained Diagrams
- **Module Relationships**: Visualizes how `composeApp`, `shared`, and `server` interact.
- **State Flow**: Details the reactive data flow between the UI and the Algorithmic Engine.
- **Platform Abstraction**: Shows how KMP handles targets like Android, JVM, and WasmJs.

For technical details on these diagrams, refer to [docs/architecture.md](../docs/architecture.md).
