## 🚀 Key Demonstrations

### 1. Dynamic Scheduling Simulation
Observe how different algorithms (like Round Robin vs SRTF) handle a set of arriving processes. Watch the **Gantt Chart** grow in real-time as the simulation progresses, calculating AWT and ATT instantly.

### 2. Interactive Deadlock Detection
Add processes and resources to the graph dynamically. Create circular waits and see the detection engine identify deadlocks and calculate the **Safe Sequence** using the Banker's safety check.

### 3. Memory Allocation & Coalescing
Simulate Continuous Memory Allocation using First-Fit, Best-Fit, Worst-Fit, or Next-Fit. Monitor **Internal and External Fragmentation** and watch the system automatically coalesce adjacent free partitions.
